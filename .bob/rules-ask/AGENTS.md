# Project Documentation Rules (Non-Obvious Only)

- **`backend/api/main.py`** is the active FastAPI entry point (CORS, agent, admin, accesibilidad, tramites routers). **`backend/main.py`** is a legacy entry point that lacks the admin router and CORS — it is no longer used. Always start the server with `uvicorn api.main:app --reload` from `backend/`.
- **`backend/skill_retys.py`** is the canonical knowledge base for RETyS BC procedures (in-memory Python dict `TRAMITES_DB`, 12 procedures). It also exports `HOMOCLAVE_MAP: dict[str, str]` — a mapping from `"BC-TYS-XXXX"` homoclave strings to `TRAMITES_DB` keys. Adding a new procedure visible from the admin panel requires: (1) adding an entry to `TRAMITES_DB`, and (2) adding the `homoclave → key` mapping to `HOMOCLAVE_MAP`.
- **`frontend/src/data/tramites.ts`** and `TRAMITES_DB` are now synchronised for the 5 frontend procedures. Each `Tramite` object in the frontend has a `homoclave` field that matches `HOMOCLAVE_MAP`. Do not add a procedure to the frontend without also adding it to `TRAMITES_DB` + `HOMOCLAVE_MAP`.
- **Lectura Fácil** (UNE 153101:2018 EX) is the core transformation all output passes through. Two modes: `"texto"` (Markdown + emojis for screen) and `"voz"` (plain text for TTS). This is a legal accessibility standard, not just a style choice.
- **Pre-generation architecture** — Lectura Fácil content is generated ONCE by an admin (via `POST /admin/tramites/{homoclave}/generar`) and stored as `.md` files in `backend/documentos/` and `.mp3` files in `backend/audios/`. Citizens retrieve pre-generated files via `GET /tramites/{homoclave}/accesible` (returns URLs) — the LLM is NOT called on citizen requests.
- **TTS/audio** — Watson TTS integration is implemented in `backend/core/tts_service.py`. It requires `TTS_API_KEY` and `TTS_URL` in `backend/.env`. If credentials are absent, `texto_a_audio()` raises `RuntimeError` and the admin endpoint gracefully skips audio (`url_audio = null`). The citizen-facing audio button falls back to `window.speechSynthesis` when `url_audio` is null.
- **SQLite (`tramites.db`)** only stores processing results (homoclave, nombre, ruta_md, ruta_audio). It does NOT store the source catalog. `create_db_and_tables()` is called in the FastAPI lifespan at startup.
- The **LSM module** (`backend/lsm/`) is experimental Mexican Sign Language support requiring a deployed Watson Machine Learning model. It is NOT part of the core citizen-facing system.
- `backend/descargar_fichas.py` downloads real RETyS BC fiches from the official government website — it requires an internet connection and is not a test fixture generator.
